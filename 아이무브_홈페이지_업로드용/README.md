# 아이무브센터 홈페이지

정적 웹사이트입니다. 빌드 도구나 서버가 필요 없고, 파일을 그대로 깃허브에 올리면 공개됩니다.

## 파일 구조

```
index.html        메인 (히어로 · 제공인력 · 제공 서비스 · 센터 둘러보기 · 채널 · 오시는 길)
about.html        센터 소개 (인사말 · 운동방법 컨셉)
therapists.html   선생님 소개 (7명, 분야 필터 + 이력 펼치기)
assets/
  css/style.css   전체 디자인. 색상은 파일 맨 위 :root 에서 한 번에 변경
  js/main.js      모바일 메뉴, 분야 필터, 사진 넘기기
  img/            로고, 선생님 사진 7장, 센터 사진 3장
```

## 깃허브 업로드

1. 저장소 첫 화면에서 **Add file → Upload files**
2. 압축을 푼 폴더 **안의 내용물**을 끌어다 놓습니다.
   `index.html` 이 저장소 최상단에 보여야 정상입니다. `imove-web` 폴더째 올리면 주소가 한 단계 깊어집니다.
3. 아래 **Commit changes** 클릭

## 홈페이지 켜기

**Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**

1~2분 뒤 `https://<깃허브아이디>.github.io/<저장소이름>/` 으로 접속됩니다.
저장소가 **Public** 이어야 무료 계정에서 공개됩니다.

## 수정 후 반영

파일을 고쳐 같은 이름으로 다시 올리면 1~2분 안에 자동 반영됩니다. 별도 배포 명령은 없습니다.

## 도메인 연결 (선택)

1. 도메인 구입 후 DNS 에 A 레코드 4개 추가
   `185.199.108.153` `185.199.109.153` `185.199.110.153` `185.199.111.153`
2. Settings → Pages → Custom domain 에 도메인 입력
3. `Enforce HTTPS` 체크 (인증서 무료 자동 발급)
